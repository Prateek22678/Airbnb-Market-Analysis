# Assumptions Log

This document records all methodological decisions, data cleaning rules, statistical assumptions, and business logic applied throughout the Airbnb Market Analysis project for Austin, TX.

---

| ID | Date | Category | Decision / Assumption | Rationale | Impact / Limitations |
|---|---|---|---|---|---|
| ASM-001 | 2026-10-14 | Setup | Target market: Austin, Texas (Inside Airbnb snapshot 2026-09-17) | High-volume market with vibrant tourism (SXSW, ACL, F1), predominantly English reviews (>99%), rich geospatial and seasonal data. | Analysis reflects post-summer 2026 market dynamics. |
| ASM-002 | 2026-10-14 | Architecture | SQLite relational model with Python processing pipeline | SQLite is lightweight, serverless, zero-configuration, fully ACID compliant, and easily queryable via standard SQL tools. | Query execution runs in-memory or on local disk; adequate for single-market scale. |
| ASM-003 | 2026-10-14 | Data Cleaning | Currency parsing: remove `$` and `,` and cast to `float64` | Raw prices stored as string formatted currency (e.g. `"$1,200.00"`). | 1,106 raw listings (9.95%) had missing price quotes and were excluded from pricing analysis. |
| ASM-004 | 2026-10-14 | Data Cleaning | Boolean conversion: `'t'` -> 1, `'f'` and nulls -> 0 | Normalizes text flags (`host_is_superhost`, `host_identity_verified`, `instant_bookable`) into binary integer indicators. | Nulls default conservatively to 0 (non-superhost / unverified). |
| ASM-005 | 2026-10-14 | Data Cleaning | Bathrooms & Capacity Imputation: Regex parsing + capacity group medians | Raw `bathrooms_text` contains strings like `"1.5 baths"`, `"Half-bath"`. Missing values in bedrooms/beds/bathrooms (<2.5%) are imputed using median values grouped by `accommodates`. | Preserves realistic architectural ratios between beds, bedrooms, and guest capacity. |
| ASM-006 | 2026-10-14 | Outlier Treatment | Price Outlier Filtering: Floor at $15/night, ceiling at 99.5th percentile ($3,080.62) | Minimum: Sub-$15 prices (10 listings) represent $0 placeholders or deposit glitches. Maximum: Prices above 99.5th percentile (50 listings) are mega-mansions that distort regression gradients and ANOVA variance assumptions. | Final cleaned sample retains 9,945 commercial listings (89.5% retention of raw; 99.4% of priced listings). |
| ASM-007 | 2026-10-14 | Feature Engineering | Forward Occupancy Proxy from Calendar: `count(available == 'f') / total_days` | Inside Airbnb marks booked or host-blocked days as `'f'`. While some blocked days are host personal use, aggregate blocking serves as industry standard occupancy proxy. | Occupancy proxy calculated over 30d (51.8%), 90d (40.6%), and 365d (37.6%) horizons. |
| ASM-008 | 2026-10-14 | Review Cleaning | Reviews text filtering: drop nulls and string length <= 3 characters | Excludes automated empty comments or one-letter noise (dropped 3,327 reviews). | Retains 650,134 valid guest reviews across 9,219 reviewed listings. |
| ASM-009 | 2026-10-15 | EDA Methodology | Minimum sample threshold of $n \ge 50$ for neighbourhood pricing rankings | Prevents low-volume peripheral ZIP codes with 5–10 listings from skewing citywide comparisons. | 25 major Austin municipal zones qualify for statistical ranking. |
| ASM-010 | 2026-10-15 | EDA Methodology | Capacity evaluation boundary: $1 \le \text{accommodates} \le 16$ | Standard Airbnb search filters cap guest capacity at 16; mega-group compounds above 16 represent specialized commercial venues. | Captures 99.8% of typical residential tourism listings. |
| ASM-011 | 2026-10-15 | EDA Methodology | Review timestamps as seasonal guest arrival proxies | Review submission dates correlate with checkout dates within 1–14 days. | Multi-year review trajectory directly reflects seasonal festival peaks (March SXSW and October ACL/F1). |
| ASM-012 | 2026-10-15 | Statistical Testing | Parametric vs Non-Parametric Pairing: Welch's t-test + Mann-Whitney U | Raw price is right-skewed; log-price is near-normal but exhibits slight variance heterogeneity (Levene's $p < 0.05$). Running paired parametric and non-parametric tests ensures conclusions are robust to distributional assumptions. | Both tests reject $H_0$ with $p < 0.001$, confirming Superhost pricing premium. |
| ASM-013 | 2026-10-15 | Statistical Testing | ANOVA & Kruskal-Wallis for Multi-Group Room Type Analysis | Evaluates whether pricing differs across 4 room tiers. Tukey HSD controls family-wise error rate ($\text{FWER} = 0.05$). | All 6 pairwise comparisons significant ($p < 0.001$); $\eta^2 = 0.138$ represents large effect size. |
| ASM-014 | 2026-10-15 | Statistical Testing | Rating Score Ceiling Clustering: Non-parametric Cliff's Delta | Review scores cluster heavily between 4.8 and 5.0 with strong negative skew, violating ANOVA normality. Cliff's Delta ($\delta = 0.171$) is used to measure true ordinal separation. | Superhosts achieve reliably superior review scores without parametric distortion. |
| ASM-015 | 2026-10-15 | Statistical Testing | Statistical Significance vs. Practical Relevance ($N=8,380$) | With large sample sizes, trivial correlations become statistically significant ($p < 0.001$). Correlation between price and ratings ($r=0.129, \rho=0.110$) explains $<2\%$ of variance ($R^2 = 1.67\%$). | Analyst concludes practical independence: price tier does not drive guest satisfaction ratings. |
| ASM-016 | 2026-10-15 | ML Modeling | Target Variable: Natural log of nightly rate `log_price` ($\ln(\text{price})$) | Normalizes right-skewed prices, stabilizes residual variance, penalizes proportional percentage error symmetrically, and guarantees positive back-transformed prices. | All models fit to log scale; predictions back-transformed via $\hat{y}_{\text{dollar}} = \exp(\hat{y}_{\text{log}})$. |
| ASM-017 | 2026-10-15 | Feature Engineering | Geographic Center: Austin City Hall / Downtown Core (30.2672° N, -97.7431° W) | Haversine great-circle distance provides a continuous metric of travel proximity to Austin's central business and entertainment hub. | Distance to downtown emerges as a top continuous spatial price driver. |
| ASM-018 | 2026-10-15 | ML Methodology | Leak-Free Pipeline & 80/20 Train-Test Split (`random_state=42`) | All transformers (StandardScaler, OneHotEncoder) fitted strictly on the 80% training partition (7,956 listings) to prevent data leakage. | Guarantees unbiased generalization assessment on the 20% test partition (1,989 listings). |
| ASM-019 | 2026-10-15 | Feature Engineering | Missing Review Imputation + Binary `has_reviews` Indicator | 1,565 listings without reviews retained by imputing domain median subscores and adding an explicit `has_reviews` binary indicator. | Eliminates selection bias without leaking future information or discarding 15.7% of the market. |
| ASM-020 | 2026-10-15 | Model Evaluation | Dual-Scale Performance Metrics (Log Units & USD $) | Reporting both scale-invariant metrics (log $R^2 = 0.7894$, log RMSE = 0.363) and intuitive business metrics (Test MAE = $96.55, Median AE = $44.13, MAPE = 27.94%). | Translates complex mathematical modeling into actionable financial decisions for property managers and hosts. |
| ASM-021 | 2026-10-15 | NLP Methodology | Review Recency Sampling: Cap at 20 most recent reviews per listing | 133,304 reviews sampled across all 9,219 reviewed listings. Recency prioritizes current property condition, current amenities, and recent host responsiveness, while preventing long-standing high-turnover listings from dominating citywide metrics. | 100% of reviewed Austin listings represented with balanced per-property weight. |
| ASM-022 | 2026-10-15 | Sentiment Analysis | VADER Lexicon Sentiment Engine on Review Texts | Rule-based lexical analyzer attuned to micro-blog and customer reviews; handles punctuation, capitalization emphasis, and negation grammar. | Generates continuous compound sentiment from -1.0 to +1.0 for each review and listing. |
| ASM-023 | 2026-10-15 | Sentiment Analysis | Standard VADER Compound Score Thresholds | Positive: compound $\ge +0.05$; Neutral: $-0.05 < \text{compound} < +0.05$; Negative: $\le -0.05$. | 94.77% positive, 3.06% neutral, 2.17% negative in Austin market. |
| ASM-024 | 2026-10-15 | Topic Modeling | Curated Domain Stopwords for Online LDA Topic Modeling | Standard English stopwords augmented with generic adjectives (`great`, `clean`, `perfect`) and local terms (`austin`, `stay`, `host`) to isolate distinct operational themes. | LDA successfully extracts 5 interpretable themes: Maintenance, Space/Pool, Experience, Host Responsiveness, and Downtown Walkability. |
| ASM-025 | 2026-10-15 | Business Insights | Review Text Sentiment to Circumvent Rating Ceiling Effect | >80% of Austin listings cluster between 4.85 and 5.00 stars. Continuous text sentiment ($r = 0.6402$ with rating) uncovers early-warning signals of guest dissatisfaction before ratings drop below the 4.80 Superhost threshold. | Early detection of maintenance friction enables proactive host intervention. |
| ASM-026 | 2026-10-15 | Dashboard Architecture | Caching Strategy: `@st.cache_data` for Ingestion, `@st.cache_resource` for ML Bundle | Prevents redundant disk I/O and deserialization across user interactions. Complete 9,945-listing dataset and XGBoost pipeline load once into server memory. | Guarantees sub-100ms dashboard re-rendering and fluid interactivity. |
| ASM-027 | 2026-10-15 | Visualization | 3D Geospatial Pydeck Scatterplot Layer with Dynamic Color Mapping | Renders 9,945 listings simultaneously with hardware acceleration. Color mapping dynamically toggles between Price Tiers, Superhost Status, Review Ratings, and Sentiment Scores. | Delivers an engaging, responsive spatial exploration tool with hover tooltips. |
| ASM-028 | 2026-10-15 | Decision Support | Real-Time Dynamic Price Simulation with Empirical Confidence Bounds | Live host tool loads the trained XGBoost model (`models/price_model_xgboost.pkl`). Back-transforms predicted $\hat{y}_{\text{log}}$ to USD and projects a 50% interquartile range using model test RMSE ($0.363$ log points). | Provides non-technical hosts with realistic pricing benchmarks and festival surge guidance. |
| ASM-029 | 2026-10-15 | Data Engineering | Forward Occupancy Metrics Integration (30d, 90d, 365d) | Calendar booking proxies linked to listings table in dashboard to provide forward-looking demand signals alongside historical pricing. | Enables hosts to balance nightly rate optimization against occupancy velocity. |
| ASM-030 | 2026-10-15 | UX Design | Clean Multi-Tab Layout with Fallback Handling & Zero-State Warnings | Tabbed hierarchy separates Spatial Maps, Market Economics, Review Intelligence, Simulator, and Strategic Playbook. Empty filter selections trigger graceful guidance warnings. | Delivers a polished, executive-ready portfolio product adhering to corporate design standards. |
